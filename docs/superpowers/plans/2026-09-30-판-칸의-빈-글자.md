# 판 칸의 빈 글자 Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 응답의 판 칸 다섯(`versions`)에 빈 글자나 공백만인 글자가 나가지 않게 한다 — 모름은 `null` 이다.

**Architecture:** 판 칸은 khala 가 준 값을 그대로 옮기고 있다. khala 는 코퍼스 판을 모를 때 빈 글자를 주고(khala 편지 24, 2026-09-30), koshei 는 응답을 엄격하게 읽어 판 칸 · `rationale` · `cause` 가 `null` 이거나 공백만이 아닌 글자(`isNotBlank`)이기를 본다(koshei, 2026-09-30). 빈 글자를 그대로 옮기면 koshei 가 실물로 붙은 뒤 khala 가 코퍼스 판을 모를 때마다 진단이 계약 위반(DIAGNOSIS_FAILED)으로 떨어진다. `rationale` 과 `cause` 는 이미 공백을 떼고 빈 것을 `null` 로 둔다 — 판 칸만 빠져 있었다. 검토(2026-09-30)가 둘을 더 찾았다 — koshei 는 빈 글자만이 아니라 공백만인 글자도 거절하고, `narratorCommit` 은 워커의 환경 변수 `NARRATOR_COMMIT` 을 떼지 않고 옮긴다.

**Tech Stack:** Python 3.13, pytest. 새 의존 없음.

**기준 시험 수:** 288 → 289. Task 1 은 기존 시험 하나를 늘리고(수 무변), Task 2 가 워커 시험 하나를 더한다.

**쓰는 규약:** 문서와 주석은 평서체. 줄끝 LF. 커밋은 제어 세션이 한다 — 작업자는 `git add` · `git commit` 을 하지 않는다. 산문의 「」는 찾거나 넣을 글자를 감싼 인용 부호다.

def _known(value):
    """판 칸 하나. **빈 글자와 공백만인 글자는 모름이라 `null` 로 옮긴다** — khala 는 코퍼스 판을 모를 때 빈 글자를
    주고(khala 편지 24), koshei 는 판 칸이 `null` 이거나 공백만이 아닌 글자이기를 본다(2026-09-30). 글자가 아닌 값도
    `null` 이다. 글자는 떼지 않고 그대로 옮긴다."""
    return value if isinstance(value, str) and value.strip() else None

        return subprocess.CompletedProcess(args, 0, stdout="f71ca2e-dirty\n")
