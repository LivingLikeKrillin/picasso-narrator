# 융합 처치 두 판의 실행기와 셈 — 실행 기록

> 설계서: `docs/superpowers/specs/2026-10-01-융합-처치-두-판.md`(판 2). 이 문서는 계획서 자리에 두는 **실행 기록**이다 — 작은 측정
> 도구라 제어 세션이 실행기와 시험을 직접 지었고, 하위 에이전트에 옮겨 적게 하지 않았다. 대신 독립 검토를 둘(설계 · 코드) 받았다.

**Goal:** khala 사전 등록(#567)의 셋째 착수 조건 — 이 층의 집합으로 T0 와 F1 을 생성 없이 여섯 판 잰다.

**Architecture:** `eval/fusion_trial.py` 하나. 실행(`run`)은 측정기의 길(`eval.recommend.client_for`, `eval/measure.py` 의
`CLIENTS` 와 같은 인자의 `nexus_client`)로 본문을 짓고 전송 함수를 감싸 `evidence_only` · `fusion_doc_agreement` 만 더한다. 셈
(`tally`)은 기록만 읽는 순수 함수다.

**Tech Stack:** Python 3, pytest.
