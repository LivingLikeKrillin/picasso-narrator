# 물음 떼기의 실행기와 셈 — 실행 기록

> 설계서: `docs/superpowers/specs/2026-10-01-물음-떼기.md`. 이 문서는 계획서 자리에 두는 **실행 기록**이다 — 질의 줄이기의 실행기를
> 가져다 쓰는 작은 측정 도구라 제어 세션이 직접 지었고, 독립 검토 하나(설계와 코드를 함께)를 받는다.

**Goal:** 질의 줄이기에서 가드에 걸린 까닭(짧은 글의 72% 를 차지하는 고정 물음이 절차 문서를 끌어온다는 가설)을, 검색 글에서 물음까지
뗀 실험군으로 생성 없이 잰다.

**Architecture:** `eval/ask_trial.py` 하나. 질의 줄이기의 `texts` 로 Q0 · Q2 를 짓고 Q3 은 Q2 에서 물음만 뺀다. 본문 짓기 · 줄 · 성립은 융합
처치 판의 것을, 부 변수는 질의 줄이기의 것을 그대로 쓴다. 셈은 질의 줄이기의 셈에 처치 검사(물음만 뺐나 · Q2 ⊆ Q3 · 토큰 차례),
후보 하나의 넘김, Q2 대 Q3, 경로와 틀린 절차의 문서별 수를 더한다. `eval/query_trial.py` · `eval/fusion_trial.py` 는 고치지 않는다.

**Tech Stack:** Python 3, pytest.

## 한 것

- [x] **설계 전 셈(판 아님).** Q3 은 사건 · 탐색 항목에서 57~409자, 질의 줄은 그대로 12~22자. 서른여섯 항목 모두 Q2 와 Q3 의 길이 차가
  물음의 길이(457)이고 토큰이 Q0 와 차례까지 같다. 서로 다른 검색은 Q2 와 같은 스물둘(기대 있는 것 열여덟), 합쳐지는 무리도 같다.
  응답에 `route_used` 가 온다(khala `/search/answer` 응답 칸)
- [x] **실행기 · 셈 · 시험.** `eval/ask_trial.py`, `tests/test_eval_ask_trial.py`(시험 일곱). 모듈을 치운 채 시험이 먼저 빨갰고(수집
  오류) 모듈과 함께 초록이다. 결함 열넷을 하나씩 실행기에 넣어 열넷 다 시험이 빨개지는 것을 봤다(물음을 안 뺌 · 조회 지시를 잃음 ·
  Q2 도 후보 · 틀린 절차 가드 뺌 · 빠진 실험군 봐줌 · 물음만 뺐나 · Q2 ⊆ Q3 · 토큰 차례 · 경로 안 적음 · 무리를 본문 해시로 ·
  khala 신원 · F1 칸 · 「판정 안 함」 대신 「없음」 · 틀린 절차 문서별 수). 시험 하나는 기대값이 틀렸었다 — 조회 지시에 토큰이 이미
  있으면 Q2 = Q1 이라 Q3 이 토큰을 다시 안 붙이는데 붙는다고 적었다. 모듈이 정의대로였고 시험을 고쳤다
- [x] **독립 검토(Opus, 설계와 코드)** — 판정 「고칠 MUST 없음, 이대로 돌려도 됨」. 검토는 읽기만 했고 서른여섯 항목을 가짜 전송으로
  지어 셌다 — 질의 말고 본문이 Q0 와 다른 항목 Q2 · Q3 다 0, 더한 키는 `evidence_only` 하나, 바뀐 항목 32 · 33, 물음만 뺐나 ·
  토큰 차례 걸린 것 0, 무리 셋의 검색 열쇠가 Q3 에서도 같음, 합쳐짐 22 · 18 과 무리 아홉이 설계서와 같음. khala 경로 함수를 읽기
  전용으로 불러 Q0 · Q2 는 `graph_then_hybrid` 29 · `hybrid_only` 3, Q3 은 `hybrid_only` 32 로 셌고, 경로가 바뀌어도 순위에 안
  닿는다(세 경로 모두 BM25 · 벡터, 엔티티 목록이 비어 그래프 보강 없음). 짧은 글이 거절 · 열화되는 자리도 없다(빈 질의만 400,
  재작성기는 이력 있을 때만, 충분성 판정자는 근거만이면 안 돎)
  - **SHOULD** — R05 처럼 Q2 가 안 바꾸는 항목에서 Q3 이 물음을 못 떼면 글자 수 검사와 포함 검사가 둘 다 건너뛴다(1), 근거 세기
    (`weak_evidence` · `top_distance` · `top_bm25`)를 적기만 하는 칸으로 판 전에 둔다(2), 응답의 식별자 토큰 검사를 이 파일 시험이
    안 건다(3)
  - **NIT** — R05 의 Q3 은 57자, 경로 문장은 사건 · 탐색 항목의 얘기, 아홉 항목 가운데 여섯만 스칼라 사실뿐, 빈 Q3 을 막는 장치,
    합쳐짐을 시험으로, Q2 판이 없을 때의 표기, 이름 겹침, 판 앞뒤 표지는 env 가 아니라 실행 스크립트 기록
- [x] **판 2 로 고침.** 위를 다 받았다 — 「Q3 이 Q0 와 같은 글이면 그 Q0 는 물음보다 짧다」를 성립에 더함, 근거 세기 칸, 빈 Q3 은
