# 생성 판(진단 경로)의 실행기와 셈 — 실행 기록

> 설계서: `docs/superpowers/specs/2026-10-02-생성-판-진단-경로.md`. 이 문서는 계획서 자리에 두는 **실행 기록**이다 — 설명 경로 판의
> 다시 부르기 · 합치기와 권고 측정기의 준비 · 시도 · 채점을 가져다 쓰는 작은 측정 도구라 제어 세션이 직접 지었고, 독립 검토 하나(설계와
> 코드를 함께)를 받는다.

**Goal:** 설명 경로에서 넘어간 처치(검색 글은 Q3, 물음과 사실은 자료 칸)를 진단 경로까지 본다 — 권고 사례 스물하나 한 바퀴로 머리 줄 ·
카드 · 깨끗함 · 금지가 깨지는가와 절차 인용이 오르는가를 잰다.

**Architecture:** `eval/gen_diag_trial.py` 하나. 계획은 사례마다 두 실험군의 (질의, 자료 칸)과 번갈아 부르는 차례, 실행은 운영 경로의
`run_diagnosis` 를 권고 측정기의 `run_case` 로 부르되 클라이언트 자리에서 함수가 지은 글을 적고 실험군의 글을 보내며, 셈은 실험군마다
줄을 `eval/recommend_score.py` 의 `score` 에 넘기고 이 판의 셈 넷을 더한다. 다시 부른 기록은 시각 차례로 합쳐 뒤의 줄이 이긴다.
`eval/recommend.py` 와 앞 판들의 실행기는 고치지 않는다.

**Tech Stack:** Python 3, pytest.

## 한 것

- [x] **설계 전 셈(판 아님).** 사례마다 Q0 · Q3 · 자료 칸 길이와 물음 떼기 첫 판의 근거에 절차가 들었나를 셌다 — D3 자료 칸 765~3,138자,
  절차 있는 스물 가운데 근거에 절차가 든 것 Q0 19 · Q3 19(갈린 것 R01 · R03), 둘 다 열여덟. 설명 경로처럼 검색이 한쪽에 얹고 시작하지
  않는다
- [x] **실행기 · 셈 · 시험.** `eval/gen_diag_trial.py`, `tests/test_eval_gen_diag_trial.py`(일곱). 모듈 없이 시험이 먼저 빨갰고(수집 오류)
  모듈과 함께 초록이다. 다시 부르기 차례의 기대값을 시험에서 잘못 적었던 것(R07 은 여섯째라 D3 먼저) 하나를 고쳤다
- [x] **결함 넣기** — 결함 스물일곱을 하나씩 넣었고 스물다섯을 시험이 잡았다. 놓친 둘(D3 자료 칸의 모양 검사 — 해시를 맞춰 바꾼 경우,
  주 변수 — 다른 가드가 함께 깨지는 경우만 시험에 있었음)을 시험에 넣어 스물일곱 다 잡는다
- [x] **독립 검토(Opus, 설계와 코드)** — 판정 「MUST 2 건을 고친 뒤 돈다」. D0 본문은 권고 측정기와 바이트까지 같고 가로채기는 건전하며
  가드 열의 이름 · 문턱 · 방향이 설계서와 같다고 봤다. 결함은 탐침으로 재현했다
  - **M1** — 다시 부르기가 사례 단위라 한쪽 실험군만 고장 난 사례를 다시 부르면 멀쩡한 쪽이 자격 위반이 되어 판이 안 선다(설명 경로
    판의 실행기도 같은 결함이었으나 그 판은 다시 부를 것이 없었다) → `--only R07:D3` 줄 단위
  - **M2** — 다시 부르는 판이 잇단 실패 둘로 멈추면 끝나지 않은 기록이 되어 「그대로 센다」가 아니라 판 전체가 안 선다 → 다시 부르는
    판은 잇단 실패로 안 멈춤(401 · 403 · 422 · `quota` · `auth` 는 그대로)
  - **SHOULD** — 모르는 판 칸(S1), 전체 판 기록 둘(S2), 실험군마다 갈리는 분모(S3 — 짝으로 셈), 되울림의 빼는 종류 · 테넌트와 보낸
    칸(S4), 주 변수는 안 나빠짐의 판정(S5)
  - **NIT** — 다시 부르기의 시도 예산(권고 측정기처럼 1 과 `rerun` 표시로), 예열이 200 이 아니면 멈춤, 시험에 없던 동작 다섯
- [x] **판 2 로 고침.** 위를 다 받았다. 시험 수는 일곱 그대로이고 기존 시험 안에 경우를 더했다(줄 단위 다시 부르기 · 한쪽만 고장 · 다시
  부르는 판의 잇단 실패 · 일시 실패 뒤 성공 · 다시 불러도 실패면 그대로 셈과 짝 · 실패 줄의 되울림 없음 · 전체 판 둘 · 모르는 판 칸 ·
  narrator 커밋 · 되울림 둘과 보낸 칸 · D3 질의 그대로 · D0 운영 글). 새 규칙에 결함 열셋을 더 넣었고, 하나(예열 실패 무시 — 시험이 잇단 실패로도 멈춰 까닭을 안 봄)를
