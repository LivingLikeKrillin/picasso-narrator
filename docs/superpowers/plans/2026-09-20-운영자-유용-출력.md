# 운영자 유용 출력 구현 계획

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 설명 층이 근거 없는 말을 하지 않으면서 **화면에 없는 것**을 말하게 한다 — 적용 절차의 첫 걸음, 후보를 가를 관측, 이 층이 본 재발 횟수, 제안된 조치의 전제.

**Architecture:** 판정은 여전히 하지 않는다(`BOUNDARY.md` §1). 바꾸는 것은 넷이다. (1) 채점기에 **절차 적중** 지표를 더해 먼저 잰다 — 정답은 답이 아니라 코퍼스의 SOP 적용 범위 표에서 온다. (2) 고정 물음 `ASK` 에 절차·갈림·금지를 묻는 문장을 더한다. (3) 이 층이 본 사건 이력에서 재발 횟수를 세어 사실로 싣는다 — 계산이지 판정이 아니다. (4) 답 앞에 운영자 카드 다섯 줄을 세우고, 탐색 줄이 짝지어진 사건에는 조치의 전제를 묻는다. 마지막에 다른 두 저장소에 보낼 요청을 쓴다.

**Tech Stack:** Python 3.11 · pytest · httpx. 실물 측정은 `nexus-app:8000` 과 `claude_llm_bridge:8900` 이 떠 있어야 한다(`STATE.md`). 한 판 20~40분.

**근거 문서(스펙):** `STATUS_REVIEW_2026-09-20-산출물.md` §6. Chunk 0 의 Task 0 에서 계획서와 함께 커밋한다.

## 지키는 규율

- **한 판에 한 묶음.** 살아 있는 스택에 골든셋을 돌리는 것은 Chunk 2 끝(J 판)과 Chunk 4 끝(K 판) 두 번뿐이다. 그 밖의 시험은 전부 픽스처로 돈다.
- **채점 규칙은 답을 보고 고치지 않는다**(`STATE.md` 함정 1). 절차 적중의 정답은 SOP §2 표와 정지 코드 문서의 조치 절이고, 골든셋에 `why` 로 그 출처를 적는다.
- **자동 수치와 판독이 다르면 둘 다 적는다.** 표본이 하나인 비율은 `1/1` 로 적는다.
- **커밋은 picasso 규약.** `type(scope): 명사구` 제목, 합니다체 본문, 마지막에 `Co-Authored-By: Claude Opus 5 <noreply@anthropic.com>`. 이력 56건이 전부 이 트레일러라 실행 모델과 무관하게 고정한다. `docs:` 처럼 scope 를 비우지 않는다. `.claude/hooks/check_commit_format.py` 가 `git commit` 을 가로채 검사하고 `scripts/hooks/commit-msg` 가 git 자체에도 같은 검사를 건다(Chunk 0).
- **훅이 막으면 우회하지 않는다.** `--no-verify` 와 훅 스크립트 수정은 쓰지 않는다. 막힌 이유를 고치고, 훅 자체가 틀렸으면 멈추고 사람에게 알린다.
- **시험 명령.** `PYTHONIOENCODING=utf-8 python -m pytest tests/<파일> -q`. 전체는 `PYTHONIOENCODING=utf-8 python -m pytest -q` 이고 지금 135 초록이다.
- **문서 문체.** 코드 주석과 문서는 평서체이고 실측은 `⛔ **… (실측 날짜)**` 로 연다. 커밋만 합니다체다.

```python
#: 본문의 인용 하나. `[출처: 제목, 절]` 또는 `[출처: 제목]`. 괄호 안 전체를 잡는다.
CITATION = re.compile(r"\[출처:\s*([^\]\n]+?)\s*\]")
#: 절 표기의 앞 번호. `§4.3` · `4. 절차` · `5.1 파지 실패` 가 전부 걸린다.
SECTION_NUMBER = re.compile(r"^§?\s*(\d+(?:\.\d+)*)")


def cited_refs(answer):
    """본문의 `[출처: …]` 안쪽 전부. **본문에서 읽는다.**

    운영자가 보는 것이 본문이고, 저쪽 인용 객체의 절 표기는 판마다 다르다(`§4.3` ·
    `1. 목적`). 검증 여부는 지표 3 이 따로 잰다 — 여기서 세는 것은 「어느 문서의 어느
    절을 짚었나」뿐이다.

    ⛔ **제목과 절을 여기서 가르지 않는다.** 절에도 쉼표가 온다(I 판 실측 — 「4. 시나리오
    ② — 부품 시퀀싱 (휴머노이드, `pick_place`)」·「15. 알려진 한계, §94」). 마지막
    쉼표로 가르면 제목이 절을 삼키고, 첫 쉼표로 가르면 쉼표 든 제목이 깨진다. 그래서
    **찾는 쪽이 제목을 먼저 맞추고** 절은 그 뒤에서 읽는다([_section_after]).
    """
    return [match.group(1).strip() for match in CITATION.finditer(answer or "")]


def _section_after(body, doc):
    """`body` 가 `doc` 을 인용한 것이면 그 뒤의 절 표기. 절 없이 제목만이면 `""`, 딴 문서면 `None`."""
    if body == doc:
        return ""
    if body.startswith(doc + ","):
        return body[len(doc) + 1:].strip()
    return None


def cites_doc(answer, doc):
    """그 문서를 한 번이라도 인용했나. 제목은 그대로 맞춰야 한다."""
    return any(_section_after(body, doc) is not None for body in cited_refs(answer))


def cites_section(answer, doc, number):
    """그 문서의 그 절(또는 그 절의 상위·하위)을 인용했나.

    `3.1` 을 기대하는데 `3. 코드별 상세` 를 인용했으면 적중이다 — 조치가 그 안에 있다.
    `5` 를 기대하는데 `5.1` 을 인용해도 적중이다. `3.2` 는 아니다.
    """
    for body in cited_refs(answer):
        section = _section_after(body, doc)
        found = SECTION_NUMBER.match(section or "")
        if not found:
            continue
        cited = found.group(1)
        if cited == number or cited.startswith(number + ".") or number.startswith(cited + "."):
            return True
    return False
```

```python
**이 층이 보태는 유일한 사실이다.** 번들에 없고 화면에도 없다. 그래서 이름에 「본 것」이
들어간다(`recurrenceSeen`) — 0 은 「없었다」가 아니라 **「이 층이 본 것 중에는 없다」**다.

**같은 사건의 재실행은 재발이 아니다.** `digest` 는 시드와 가상 시계에서 나오는 결정적
값이라 같은 시나리오를 다시 돌리면 그대로 반복된다(§3.4). 그래서 `digest` 가 다른 것만
세고, 같은 `digest` 는 한 번만 센다. **현재 사건보다 뒤의 것은 안 센다** — 재발은 앞에
있었던 것이다.
"""

#: 재발을 가르는 데 필요한 칸. 이것만 기록에 남긴다 — 번들 전체를 다시 적을 이유가 없다.
SUBJECT_KEYS = ("robotId", "failureClass", "unitId", "at", "digest")


def subject(bundle):
    """번들에서 주체만. **없는 칸은 안 싣는다** — 널을 값으로 바꾸지 않는다."""
    return {key: bundle[key] for key in SUBJECT_KEYS if bundle.get(key) is not None}


def count_recurrence(current, prior):
    """`current` 앞에 같은 기체·같은 분류 / 같은 자리·같은 분류가 몇 번 있었나.

    :param prior: 주체 사전들 — 저장소가 본 것과 지금 한 벌의 것을 합친 목록.
    :returns: ``{"sameRobotSameClass": n, "sameUnitSameClass": m}``
    """
    me = subject(current)
    counted = set()
    same_robot = same_unit = 0
    for other in prior:
        digest = other.get("digest")
        if not digest or digest == me.get("digest") or digest in counted:
            continue
        if other.get("failureClass") != me.get("failureClass"):
            continue
        if me.get("at") and other.get("at") and other["at"] > me["at"]:
            continue
        counted.add(digest)
        if other.get("robotId") == me.get("robotId"):
            same_robot += 1
        if other.get("unitId") and other.get("unitId") == me.get("unitId"):
            same_unit += 1
    return {"sameRobotSameClass": same_robot, "sameUnitSameClass": same_unit}
```

```python
def explain(batch, search, limit=3, prior=()):
    """…기존 docstring 본문 그대로…

    :param prior: 저장소가 본 사건의 주체. 이 한 벌의 것(`batch.history`)과 합쳐

        빠진다.
    """

    records = []
    for bundle in batch.incidents:
        query = compose(bundle, recurrence=count_recurrence(bundle, history))
        records.append(_one(bundle, query, batch.manifest, search, limit, who=subject(bundle)))
```

```python
것을 표지 다섯 줄로 앞에 세운다 — 절차 · 먼저 · 금지 · 갈림 · 근거 세기.

**파싱은 결정적이다.** 표지가 없으면 카드가 없는 것이고 지어내지 않는다. 표지마다 인용
하나를 요구하므로(`composer.CARD_NOTE`) 근거 없는 줄은 「근거 없음」이 된다.

표지 다섯에 「무엇」과 「왜」가 없는 것은 의도다 — 무엇이 일어났는지는 화면에 이미 있고

앞 [HEAD_LINES] 줄만 본다. 본문 한가운데의 「금지:」는 카드가 아니다. 모델이 표지 앞에
머리말을 길게 두면 카드를 못 읽는데, 그것은 **덜 세는 쪽**으로 틀리는 것이다.
"""

import re

LABELS = ("절차", "먼저", "금지", "갈림", "근거 세기")

#: 한 줄. 글머리표와 굵게를 허용한다 — 모델이 마크다운으로 꾸며도 표지는 표지다.
#: 굵게는 콜론 앞(`**먼저**:`)에서도 뒤(`**절차:**`)에서도 닫힐 수 있어 둘 다 받는다.
LINE = re.compile(
    r"^\s*(?:[-*]\s*)?(?:\*\*)?(절차|먼저|금지|갈림|근거 세기)(?:\*\*)?\s*[:：]\s*(?:\*\*)?\s*(\S.*?)\s*$"

    card = {}
    for line in (answer or "").splitlines()[:HEAD_LINES]:
        match = LINE.match(line)
        if match and match.group(1) not in card:
            card[match.group(1)] = match.group(2)
    return card
```
