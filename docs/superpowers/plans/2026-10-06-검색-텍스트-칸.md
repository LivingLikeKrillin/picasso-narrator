# 검색 텍스트 칸(두 경로)의 실행기와 평가 도구 — 실행 기록

> 설계서: `docs/superpowers/specs/2026-10-06-검색-텍스트-칸.md`(버전 2). 이 문서는 계획서 자리에 두는 **실행 기록**이다 — 앞 두 생성
> 실행의 실행기(`eval/gen_trial.py` · `eval/gen_diag_trial.py`)와 권고 측정기의 준비 · 시도 · 채점을 가져다 쓰는 작은 측정 도구라 제어
> 세션이 직접 짓고, 독립 검토 하나(설계와 코드를 함께)를 받는다. 할 일은 점검 목록이고 끝나면 표시한다. 이 계획서는 독립 검토(Opus)
> 하나를 받아 고쳤다(MUST 하나, SHOULD 여섯).

**Goal:** 설계서의 실행 두 번(설명 경로 G0 · GS, 진단 경로 D0 · DS)을 돌릴 실행기와, 기록만 읽어 성립 · 지표 · 승격을 내는 평가 도구를
만든다.

**Architecture:** `eval/st_trial.py` 하나. 계획은 경로마다 실험군의 질의 · 답변 컨텍스트 · `search_text` 와 번갈아 부르는 차례, 실행은
운영 클라이언트 `nexus_client` 가 지은 본문에 전송 자리에서 `search_text` 만 더하되 줄마다 기록을 다시 쓰고 `complete` 는 끝에서만 참이며
다시 부르기는 줄 단위, 평가 도구는 제목 짝으로 기록을 읽은 뒤 앞 두 실행의 지표 · 가드레일 지표를 그대로 쓰고 성립 검사를 더한다.
`eval/gen_trial.py` · `eval/gen_diag_trial.py` · `eval/recommend.py` · `eval/measure.py` · `eval/score.py` · `eval/recommend_score.py` 는
고치지 않는다.

**Tech Stack:** Python 3, pytest.
