# 생성 판(설명 경로)의 실행기와 셈 — 실행 기록

> 설계서: `docs/superpowers/specs/2026-10-01-생성-판-설명-경로.md`. 이 문서는 계획서 자리에 두는 **실행 기록**이다 — 물음 떼기의
> 글 짓기와 골든셋 채점을 가져다 쓰는 작은 측정 도구라 제어 세션이 직접 지었고, 독립 검토 하나(설계와 코드를 함께)를 받는다.

**Goal:** 물음 떼기에서 넘어간 Q3 을 생성까지 본다 — 검색 글은 Q3, 물음과 사실은 자료 칸(Q0 통째로)으로 옮기면 설명이 깨지는가와 절차
인용이 오르는가를 골든셋 한 바퀴로 잰다.

**Architecture:** `eval/gen_trial.py` 하나. 계획은 항목마다 두 실험군의 (질의, 자료 칸)과 번갈아 부르는 차례, 실행은 운영 경로의
`nexus_client` · `ask_and_record` 로 보내고 보낸 본문을 붙잡아 sha256 을 적으며, 셈은 기록의 줄을 `Record` 로 되지어 `eval/score.py`
의 `score` 에 넘긴다. 다시 부른 기록은 시각 차례로 합쳐 뒤의 줄이 이긴다. `eval/measure.py` 와 앞 판들의 실행기는 고치지 않는다.

**Tech Stack:** Python 3, pytest.

## 한 것

- [x] **설계 전 셈(판 아님).** 탐색 에이전트가 두 생성 경로를 정리했다 — 골든셋 측정기는 15항목 순차 약 38분이고 기록을 덮어쓰며
  시험이 그 줄들을 글자로 박는다(그래서 새 실행기), 진단 경로는 `run_diagnosis` 가 질의를 인자로 안 받는다(그래서 이 판은 설명 경로만),
  자료 칸은 가장 긴 G1 도 2,404자, 다섯 표지는 물음에만 정의되어 있어 카드 완성이 자료 칸의 형식 지시를 따르는지의 표지다
- [x] **실행기 · 셈 · 시험.** `eval/gen_trial.py`, `tests/test_eval_gen_trial.py`(시험 여섯, 검토 뒤 일곱). 모듈을 치운 채 시험이 먼저 빨갰고(수집
  오류) 모듈과 함께 초록이다. 결함 열넷을 하나씩 넣어 열넷 다 시험이 빨개지는 것을 봤다(G3 자료 칸 없음 · G3 질의를 Q0 로 · 차례 고정
  · 식별자 채널 끔 · 422 에서 안 멈춤 · 연속 실패에도 안 접음 · 처치 검사 · khala 신원 · 검색 고장 · 판 칸 · 카드 가드 좁힘 · 주 변수
  뒤집음 · 다시 부른 줄 대신 첫 줄 · 모른다 가드). 고장 항목만 다시 부르는 `--only` 와 기록 여럿을 합치는 셈을 더했다
- [x] **독립 검토(Opus, 설계와 코드)** — 판정 「MUST 2 건을 고친 뒤 돈다」. 보내는 요청에는 고칠 것이 없었다 — G0 본문 15/15 가
  측정기(T2)와 같고 G3 은 질의와 자료 칸만 다르다, 되지은 `Record` 의 채점이 원래와 같다(무작위 300 벌), 문턱이 설계서와 코드에서 같다,
  누출 없음, 차례 맞음
  - **M1** — 주 변수가 이미 잰 검색 효과로 거의 정해진다(받은 절차 G0 7/10 · G3 10/10). G3 이 둘 다 받은 사건에서 셋을 덜 인용해도
    넘어간다 → 둘 다 받은 사건의 인용을 여덟째 가드로
  - **M2** — 생성 실패를 다루는 규칙이 없다. G3 쪽 실패 하나가 판을 막고 G0 쪽 실패는 분모를 줄여 G3 을 돕는다 → 다시 할 만한
    실패는 판 끝에 한 번 다시, 「분모는 같다」 문장 고침
  - **SHOULD** — 서버의 되울림을 안 남김(S1), 다시 부른 기록이 무엇이든 덮음(S2), 앞 판과의 견줌이 셈에 없음(S3), 항목 서술에 절차
    인용이 없음(S4), 물러남의 서술이 없음(S5), 처치가 묶음(S6), 측정기 본문과의 대조 시험(S7)
  - **NIT** — 「모른다」 가드는 처치를 안 잰다(두 실험군이 같은가로), JSON 아닌 응답의 `ValueError`, 접는 메시지에 실험군, 예열은
    검색만 데움, 이름 겹침, 기록 폴더
- [x] **판 2 로 고침.** 위를 다 받았다 — 가드 여덟(둘 다 받은 사건의 인용 · 「모른다」는 두 실험군이 같은가), 다시 부를 실패와 다시
  부른 줄의 자격, 응답의 되울림 기록과 자료 칸 길이 대조, 앞 판(물음 떼기 첫 판)과 근거 문서 집합 견줌, 사건의 약함 · 물러남 수와 항목의
  절차 인용 · 근거에 들었나, JSON 아닌 응답은 전송 실패로. 시험 하나를 더했다(일곱). 결함 넷을 더 넣어 모두 열여덟을 시험이 다 잡는
