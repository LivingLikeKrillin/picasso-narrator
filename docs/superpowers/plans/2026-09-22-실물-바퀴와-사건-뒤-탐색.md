> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** picasso 가 낸 「사건 뒤에 탐색이 서는 한 벌」(run-4)을 픽스처로 들이고 골든셋에 짝 둘을 넣어 회복 설명을 표본 둘 이상으로 잴 수 있게 한다. 같은 날 실물 승인 창구로 돈 두 바퀴를 대장 그대로 픽스처로 남기고 문서에 적는다. 그 위에서 측정을 한 판 돈다.

**Architecture:** 실행 경로는 안 바뀐다(`BOUNDARY.md` §4.1 — 사건과 탐색은 각각 다룬다). 짝은 골든셋 항목의 `search` 칸에만 있고 그것은 평가에만 있는 자리다(`eval/run.py::query_for` 머리말). 재는 것은 절차 적중(자동)과 제안된 조치의 전제 대조(판독)다. 실물 바퀴의 대장은 `AttemptStore` 가 되읽는 픽스처가 된다.

**Tech Stack:** Python 3.11 · pytest. Task 1·2 는 스택 없이 돈다. Task 3 만 실물 스택이 필요하다(20~50분).

**근거 문서(스펙):** picasso 회신 `handoff/narrator/TO-NARRATOR-2026-09-22-사건-뒤-탐색.txt` 와 그쪽 INDEX 의 run-4 절. 길은 **사건 → 사람의 재작업 → 탐색**이고 자동 회복이 아니다 — 설명에서 그 걸음을 빼면 안 된다. 짝은 시각이 아니라 기체로 잡는다. `at` 간격은 여유이지 보장이 아니고 보장은 「탐색이 사건보다 뒤」 하나다.
