**Goal:** 표지 줄 사이에 빈 줄이 끼어 다섯째 표지가 답의 13번째 줄 아래로 밀려도 카드와 본문이 그 표지를 머리로 읽게 한다.

`recorder/card.py` 의 `HEAD_LINES = 12` 아래, `parse_card` 앞에 넣는다:

```python
def head_window(lines, marker):
    """머리 창의 줄 번호 — 앞 [HEAD_LINES] 줄, 그리고 그 머리가 이어지는 데까지.

    ⛔ **끝까지 한 번의 응답 카드가 넷이었다 (2026-10-04).** 모델이 표지 줄마다 빈 줄을 띄우면 다섯째 표지가 13번째
    줄로 밀린다. 앞 12줄 안에서 **글이 있는 마지막 줄이 표지 줄이면**(`marker`) 창은 그 뒤로 표지 줄과 빈 줄이
    이어지는 데까지 늘어난다. 글이 있는 다른 줄이 오면 끝난다 — 본문 한가운데의 표지는 여전히 머리가 아니고,
    앞 12줄에 글이 없으면 늘지 않는다. 창은 넓어지기만 한다 — 앞 12줄은 언제나 창 안이다.
    """
    n = min(len(lines), HEAD_LINES)
    window = list(range(n))
    last = next((i for i in range(n - 1, -1, -1) if lines[i].strip()), None)
    if last is not None and marker(lines[last]):
        i = n
        while i < len(lines) and (not lines[i].strip() or marker(lines[i])):
            window.append(i)
            i += 1
    return window
```

```python
def parse_card(answer):
    """머리 창(`head_window`)의 표지 줄을 `{표지: 문장}` 으로. **하나도 없으면 빈 사전.**"""
    card = {}
    lines = (answer or "").splitlines()
    for i in head_window(lines, LINE.match):
        match = LINE.match(lines[i])
        if match and match.group(1) not in card:
            card[match.group(1)] = match.group(2)
    return card
```
