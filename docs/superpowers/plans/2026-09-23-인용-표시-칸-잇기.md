**Goal:** khala 의 답변 경로가 인용 항목에 싣기 시작한 출처 등급(`provenance_tier`)과 렌더된 표시(`provenance_mark`)를, 이 층이 인용을 다시 적는 표면 둘 — 측정 기록의 `citationRefs` 와 설명 기록 내보내기의 「인용」 절 — 이 떨어뜨리지 않게 한다.

**Tech Stack:** Python 3.11 · pytest. 스택 없이 돈다.

**근거:** khala 회신(2026-09-23, `correspondence/TO-KHALA-2026-09-23-소유자-결정-넷.md` 열일곱째 후기) — 인용 항목이 `{"title","section","verified","provenance_tier","provenance_mark"}` 다섯을 든다. `machine_written` 의 표시는 ` [LLM 이 만든 설명]`(앞 공백 포함), `authored` 는 빈 문자열. 실측 — 셋째 운영자 질의의 인용 11 건이 그 모양으로 왔다. `STATE.md` 「종결 기준과 마감」의 1 번이다.

```python
def cited_lines(record):
    """인용 한 줄씩. **표시는 khala 가 렌더해 보낸 문자열을 그대로 붙인다**(`provenance_mark`, 2026-09-23) —
    등급으로 문자열을 고르면 표면마다 다른 말이 되므로 이 층은 옮기기만 한다. 없거나 빈 문자열이면 그대로다."""
    lines = []
    for c in record.citations or []:
        where = f"{c.get('title')}{c.get('provenance_mark') or ''}" + (f" · {c.get('section')}" if c.get("section") else "")
        lines.append(f"- {where} · {'검증됨' if c.get('verified') else '검증 안 됨'}")
    return lines or ["(인용 없음)"]
```

Run: `PYTHONIOENCODING=utf-8 python -m pytest tests/test_corpus_export.py -q`
Expected: 전부 초록(기존 열 + 하나).
