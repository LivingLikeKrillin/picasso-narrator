# 운영 검색 텍스트의 구현과 확인 — 실행 기록

> 설계서: `docs/superpowers/specs/2026-10-07-운영-검색-텍스트.md`(버전 2, `51e4bac`). 이 문서는 계획서 자리에 두는 **실행 기록**이다 — 운영
> 코드 다섯 곳의 작은 변경과 같음 시험이라 하위 에이전트 하나가 시험부터 짓고, 독립 검토 하나(설계와 코드를 함께)를 받는다. 할 일은
> 점검 목록이고 끝나면 표시한다.

**Goal:** 운영 경로 둘(수신기 파이프라인 · 진단 워커)이 khala 에 보내는 본문에 `search_text` = Q3 을 더하고, 그 본문이 검색 텍스트 칸
측정의 GS · DS 본문과 같다는 것을 실제 서비스 없이 시험으로 보인 뒤, 실제 서비스에서 배선을 한 번 확인한다.

**Architecture:** `composer/query.py` 의 `Query` 가 Q3 을 짓고(`search_text`), `nexus_client` 의 `search` 가 선택 인자로 받아 비지 않을
때만 키를 싣고, `ask_once` · `ask_and_record` 는 넘겨받기만 한다. 켜는 자리는 수신기 `_one` 과 워커 `main` 뿐이고 `run_diagnosis` ·
`diagnose` 의 켜는 인자는 기본 꺼짐이다. 앞 실행기 · 측정기는 고치지 않는다.

**Tech Stack:** Python 3, pytest.
